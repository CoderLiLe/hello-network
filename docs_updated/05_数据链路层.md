# 数据链路层

> 讲师: 李明杰 (小码哥教育)

## 概述

数据链路层（Data Link Layer）负责在相邻节点之间可靠地传输数据帧。

### 基本概念
- **链路**：从一个节点到相邻节点的一段物理线路（有线或无线），中间没有其他交换节点
- **数据链路**：在链路上传输数据时，需要有对应的通信协议来控制数据的传输

### 协议分类
- **广播信道**：CSMA/CD 协议（如同轴电缆、集线器等组成的网络）
- **点对点信道**：PPP 协议（如 2 个路由器之间的信道）

## 数据链路层的 3 个基本问题

### 1. 封装成帧
- **帧（Frame）** 的数据部分就是网络层传递下来的数据包（IP 数据包，Packet）
- **MTU（Maximum Transfer Unit）**：最大传输单元
  - 每种数据链路层协议都规定了所能够传送的帧的数据长度上限
  - 以太网的 MTU 为 **1500 字节**

### 2. 透明传输
- 使用 **SOH（Start Of Header）** 作为帧开始符
- 使用 **EOT（End Of Transmission）** 作为帧结束符
- 数据部分一旦出现 SOH、EOT，需要进行转义

### 3. 差错检验
- **FCS（Frame Check Sequence）**：帧检验序列
- 根据数据部分 + 首部计算得出

## CSMA/CD 协议

CSMA/CD（Carrier Sense Multiple Access with Collision Detection）：载波侦听多路访问/冲突检测

- 使用了 CSMA/CD 的网络可以称为**以太网（Ethernet）**
- 以太网帧的格式有：Ethernet V2 标准、IEEE 802.3 标准（使用最多的是 Ethernet V2）
- 为了检测冲突，以太网帧至少需要 **64 字节**
- 用交换机组建的网络已支持全双工通信，不需要 CSMA/CD，但仍传输以太网帧

## 以太网帧格式

### 帧结构
| 字段 | 长度 (字节) | 说明 |
|------|-------------|------|
| 目标 MAC | 6 | 接收方 MAC 地址 |
| 源 MAC | 6 | 发送方 MAC 地址 |
| 网络类型 | 2 | 上层协议类型 |
| 数据 | 46~1500 | IP 数据包 |
| FCS | 4 | 帧检验序列 |

### 长度总结
- 以太网帧的数据长度：**46 ~ 1500** 字节
- 以太网帧的长度：**64 ~ 1518** 字节（含首部和 FCS）
- 当数据小于 46 字节时，会在数据后面加入填充字节

## 网卡的工作方式
- 网卡接收到一个帧，首先进行差错校验，通过则接收，否则丢弃
- Wireshark 抓到的帧没有 FCS，因为它是差错校验通过后的帧（FCS 已被硬件去掉）

## PPP 协议

PPP（Point-to-Point Protocol）：点对点协议
- Address 字段：值为 `0xFF`，点到点信道不需要源 MAC、目标 MAC 地址
- Control 字段：值为 `0x03`，目前没有实际作用
- Protocol 字段：内部用到的协议类型
- 帧开始符、帧结束符：`0x7E`

### 字节填充
- `0x7E` → `0x7D 5E`
- `0x7D` → `0x7D 5D`
