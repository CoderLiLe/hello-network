# 网络层

> 讲师: 李明杰 (小码哥教育)

## 概述

网络层数据包（IP 数据包，Packet）由首部和数据 2 部分组成。数据很多时候是由传输层传递下来的数据段（Segment）。

## IP 数据包首部格式

### 1. 版本 (Version) - 4 位
- `0b0100`：IPv4
- `0b0110`：IPv6

### 2. 首部长度 (Header Length) - 4 位
- 二进制值乘以 4 才是最终长度
- `0b0101`：20 字节（最小值）
- `0b1111`：60 字节（最大值）

### 3. 区分服务 (Differentiated Services Field) - 8 位
- 可用于提高网络的服务质量（QoS）

### 4. 总长度 (Total Length) - 16 位
- 首部 + 数据的长度之和，最大值 65535
- 由于帧的数据不能超过 1500 字节，过大的 IP 数据包需要**分片（Fragments）**

### 5. 标识 (Identification) - 16 位
- 数据包的 ID，分片时同一数据包的所有片标识相同
- 每发出一个数据包，ID 就加 1

### 6. 标志 (Flags) - 3 位
- 第 1 位 (Reserved Bit)：保留
- 第 2 位 (Don't Fragment)：
  - 1：不允许分片
  - 0：允许分片
- 第 3 位 (More Fragments)：
  - 1：不是最后一片
  - 0：是最后一片

### 7. 片偏移 (Fragment Offset) - 13 位
- 片偏移 × 8 = 字节偏移
- 每一片的长度一定是 8 的整数倍

### 8. 生存时间 (TTL) - 8 位
- 每个路由器转发前将 TTL 减 1，TTL 为 0 时返回错误报告
- 通过 TTL 可以推测对方操作系统和经过的路由器数量

| 操作系统 | 默认 TTL |
|----------|----------|
| Windows | 128 |
| Linux | 64 |
| Mac | 64 |

### 9. 协议 (Protocol) - 8 位
表明所封装的数据使用了什么协议：
| 协议 | 值 (十进制) |
|------|-------------|
| ICMP | 1 |
| TCP | 6 |
| UDP | 17 |

### 10. 首部校验和 (Header Checksum)
- 用于检查首部是否有错误

## 常用网络命令

| 命令 | 说明 |
|------|------|
| `ping /?` | 查看 ping 的用法 |
| `ping ip -l 数据包大小` | 发送指定大小的数据包 |
| `ping ip -f` | 不允许网络层分片 |
| `ping ip -i TTL` | 设置 TTL 的值 |
| `tracert ip` | 跟踪数据包经过的路由器（Windows） |
| `pathping ip` | 跟踪并分析路径（Windows） |
