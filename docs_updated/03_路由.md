# 路由

> 讲师: 李明杰 (小码哥教育)

## 路由基础

在不同网段之间转发数据，需要有路由器的支持。默认情况下，路由器只知道与它直连的网段，非直连的网段需要通过路由协议告诉它。

### 静态路由 vs 动态路由

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 静态路由 | 管理员手动添加路由信息 | 小规模网络 |
| 动态路由 | 路由器通过路由协议（如 RIP、OSPF）自动获取路由信息 | 大规模网络 |

## 路由表

路由器的路由表中包含以下类型的路由：

| 路由类型 | 说明 |
|----------|------|
| 网络路由 | 到特定网络的路径 |
| 特定主机路由 | 到特定主机的路径 |
| 默认路由 | 当没有匹配路由时使用的路径 |
| 汇总路由 | 聚合多个网络的路由 |

路由表中的关键信息：
- **网络**：目标网络地址
- **子网掩码**：目标网络的子网掩码
- **下一跳**：下一跳路由器的 IP 地址

## 网络、互联网、因特网

| 术语 | 说明 |
|------|------|
| 网络 (Network) | 由若干节点和连接这些节点的链路构成 |
| 互联网 (Internet) | 将多个网络连接起来 |
| 因特网 (Internet) | 全世界最大的互联网，将全球计算机连接在一起 |

> 日常生活中说的"你的电脑上不了网"，就是指你的电脑没有连接到因特网。

## ISP

ISP（Internet Service Provider）：Internet 服务提供商，如移动、电信、联通等。我们平时拉的宽带都是通过 ISP 连接到 Internet 的。

### 服务器机房
- 电信机房
- 移动机房
- 双线机房（同时接入电信和移动）

## 网络分类

| 类型 | 范围 | 说明 |
|------|------|------|
| 局域网 (LAN) | 几百米~十几公里 | 公司、家庭、学校等，最常用的是以太网 |
| 城域网 (MAN) | 数十公里~数百公里 | 覆盖一个城市 |
| 广域网 (WAN) | 几百公里~几千公里 | 覆盖一个国家，通常需租用 ISP 线路 |

> **WLAN**（Wireless LAN）：无线局域网

## 常见的接口类型
- **FastEthernet**：快速以太网接口（100M）
- **GigabitEthernet**：千兆以太网接口
- **Serial**：串行接口

## 上网方式

### 电话线入户 (ADSL)
- ADSL（Asymmetric Digital Subscriber Line）：非对称数字用户线路
- 需要**猫（Modem）**：调制解调器，进行数字信号和模拟信号的转换

### 光纤入户
- 需要**光猫（Optical Modem）**：光调制解调器，进行数字信号和光信号的转换

### 网线入户
- 直接使用网线连接

## 家用无线路由器

家用无线路由器实际上集成了多种功能：
- **无线接入点**：提供 Wi-Fi 连接
- **交换机**：提供有线网络连接
- **路由器**：实现网络层路由转发
- **宽带猫功能**：部分路由器集成

## 公网 IP 与私网 IP

### 公网 IP (Public)
- Internet 上的路由器中只有到达公网的路由表
- 由 ICANN（因特网信息中心）统一分配和管理

### 私网 IP (Private)
主要用于局域网，以下是保留的私网网段：
- A 类：`10.0.0.0/8`（1 个 A 类网络）
- B 类：`172.16.0.0/16` ~ `172.31.0.0/16`（16 个 B 类网络）
- C 类：`192.168.0.0/24` ~ `192.168.255.0/24`（256 个 C 类网络）

### NAT (网络地址转换)
私网 IP 访问公网需要进行 NAT 转换为公网 IP。

**NAT 的分类：**
1. **静态转换**：手动配置，一对一转换
2. **动态转换**：定义外部地址池，动态随机转换，一对一转换
3. **PAT（端口地址转换）**：多对一转换，采用端口多路复用，是目前最广泛的方式

NAT 的特点：
- 节约公网 IP 资源
- 隐藏内部真实 IP
