## 域名系统 (DNS)

### 域名结构
由于 IP 地址不方便记忆，人们设计出了域名（如 `baidu.com`）。

**域名的级别：**
- **顶级域名 (TLD)**
  - 通用顶级域名 (gTLD)：`.com`、`.net`、`.org`、`.edu`、`.gov`
  - 国家及地区顶级域名 (ccTLD)：`.cn`、`.jp`、`.uk`
  - 新通用顶级域名 (New gTLD)：`.vip`、`.xyz`、`.top`
- **二级域名**：如 `google`、`baidu`、`microsoft`
- **三级域名**：如 `www`

### DNS 解析
DNS（Domain Name System）：将域名解析成对应的 IP 地址。
- DNS 可以基于 UDP 或 TCP 协议
- 服务器占用 **53 端口**

### DNS 查询过程
1. 客户端访问最近的一台 DNS 服务器
2. 根域名服务器记录了下级 DNS 服务器的 IP 地址
3. 逐级查询直到得到最终结果
4. 全球一共 **13 台 IPv4 的 DNS 根域名服务器**

### 常用命令
| 命令 | 说明 |
|------|------|
| `ipconfig /displaydns` | 查看 DNS 缓存记录 |
| `ipconfig /flushdns` | 清空 DNS 缓存记录 |
| `ping 域名` | 测试域名连通性 |
| `nslookup 域名` | 查询域名解析详情 |

## DHCP (动态主机配置协议)

DHCP 基于 UDP 协议，客户端使用 **68 端口**，服务器使用 **67 端口**。

### IP 地址分配的 4 个阶段
1. **DISCOVER**：发现服务器（发送广播包）
2. **OFFER**：提供租约（服务器返回可用 IP 等信息）
3. **REQUEST**：选择 IP（客户端选择一个 OFFER）
4. **ACKNOWLEDGE**：确认（服务器发送 ACK）

### 细节
- DHCP 可以跨网段分配 IP 地址（通过 DHCP 中继代理）
- 客户端会在租期不足时自动申请续约

**常用命令：**
| 命令 | 说明 |
|------|------|
| `ipconfig /all` | 查看 DHCP 详细信息 |
| `ipconfig /release` | 释放租约 |
| `ipconfig /renew` | 重新申请 IP 或续约 |

### 静态 IP vs 动态 IP
| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 静态 IP | 手动设置 | 台式机、服务器 |
| 动态 IP | 从 DHCP 自动获取 | 移动设备、无线设备 |
