## 网络爬虫

网络爬虫（Web Crawler / Web Spider）：模拟人类使用浏览器操作页面的行为，对页面进行相关操作。

**常用工具**：Python 的 Scrapy 框架

### robots.txt
- 存放于网站根目录的文本文件（如 `https://www.baidu.com/robots.txt`）
- 告诉爬虫哪些内容不应被爬取
- 不是规范，只是约定俗成
- 只能防君子，不能防小人

### 简易爬虫
可使用 Java 的小框架 Jsoup 爬取简单数据：
- jar 包：https://jsoup.org/packages/jsoup-1.13.1.jar

**搜索引擎工作流程：**
1. 爬虫爬取网页
2. 建立索引
3. 用户搜索时返回结果

## VPN (虚拟私人网络)

VPN（Virtual Private Network）：在公共网络上建立专用网络，进行加密通讯。

### 作用
- 提高上网安全性
- 保护公司内部资料
- 隐藏上网者身份
- 突破网站地域限制
- 突破网络封锁

### 实现原理
VPN 使用**隧道协议（Tunneling Protocol）**：
| 协议 | 说明 |
|------|------|
| PPTP | 点对点隧道协议 |
| L2TP | 第二层隧道协议 |
| IPsec | 互联网安全协议 |
| SSL VPN | 如 OpenVPN |

### VPN vs 代理
| 对比项 | VPN | 代理 |
|--------|-----|------|
| 软件 | 需要安装客户端 | 不需要额外软件 |
| 安全性 | 默认加密数据 | 默认不加密 |
| 费用 | 一般较贵 | 一般较便宜 |
