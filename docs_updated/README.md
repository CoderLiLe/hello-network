## 核心技术要点

| 主题 | 核心内容 |
|------|----------|
| 网络模型 | OSI 7 层模型、TCP/IP 4 层模型、5 层实用模型 |
| 地址体系 | MAC 地址、IP 地址、子网掩码、子网划分 |
| 路由原理 | 静态路由、动态路由、NAT 转换 |
| TCP/UDP | 三次握手、四次挥手、流量控制、拥塞控制 |
| HTTP 协议 | 报文格式、请求方法、状态码、缓存机制 |
| 网络安全 | 加密技术、数字签名、证书体系 |
| 协议升级 | HTTP/2 多路复用、HTTP/3 QUIC 协议 |

## 学习建议

1. **按顺序学习**：从基础概念开始，逐步深入到具体协议
2. **结合实践**：配合 Wireshark 抓包工具进行实际报文分析
3. **动手操作**：搭建 Java Web 服务器，实现简单的 HTTP 通信
4. **面试准备**：重点关注 TCP 三次握手/四次挥手、HTTP 状态码、加密技术等高频考点

## 推荐工具

- **抓包分析**：Wireshark、Fiddler、Charles
- **网络模拟**：Packet Tracer、GNS3
- **开发环境**：IntelliJ IDEA + Tomcat
- **调试命令**：ping、tracert、netstat、nslookup、telnet
