# 物理层

> 讲师: 李明杰 (小码哥教育)

## 概述

物理层（Physical Layer）定义了：
- 接口标准
- 线缆标准
- 传输速率
- 传输方式

## 数字信号 vs 模拟信号

| 特性 | 模拟信号 (Analog Signal) | 数字信号 (Digital Signal) |
|------|------------------------|--------------------------|
| 连续性 | 连续信号 | 离散信号 |
| 传输距离 | 适合长距离 | 不适合长距离 |
| 抗干扰能力 | 差，波形变形难纠正 | 强，波形失真可修复 |

## 数据通信模型

### 局域网通信模型
```
集线器/交换机
    ├── 网线 ── 计算机（数字信号）
    └── 网线 ── 计算机（数字信号）
```

### 广域网通信模型

**电话线通信：**
```
计算机 ←网线→ 调制解调器 ←电话线(模拟信号)→ 调制解调器 ←网线→ 计算机
```

**光纤通信：**
```
计算机 ←网线→ 光电转换器 ←光纤(光信号)→ 光电转换器 ←网线→ 计算机
```

> 注意：网线不能超过 100 米

## 信道 (Channel)

信道：信息传输的通道，一条传输介质上可以有多条信道。

### 通信方式分类

| 方式 | 说明 | 示例 |
|------|------|------|
| 单工通信 | 信号只能往一个方向传输，任何时候不能改变方向 | 无线电广播、有线电视 |
| 半双工通信 | 信号可以双向传输，但必须交替进行，同一时间只能往一个方向传输 | 对讲机 |
| 全双工通信 | 信号可以同时双向传输 | 手机通话 |

## 网络互连模型回顾

物理层位于 OSI 模型的最底层，负责将数据链路层的帧转换为比特流，通过物理介质传输。

```
应用层    - 报文 (FTP, HTTP, SMTP, DNS, DHCP)
运输层    - 段 (TCP, UDP)
网络层    - 包 (IP, ARP, ICMP)
数据链路层 - 帧 (CSMA/CD, PPP)
物理层    - 比特流
```
