# MAC 地址 & IP 地址

> 讲师: 李明杰 (小码哥教育)

## MAC 地址

### 概述
- 每一个网卡都有一个 48 位（6 字节）的 MAC 地址（Media Access Control Address）
- **全球唯一**，固化在网卡的 ROM 中，由 IEEE 标准规定
- 前 3 字节：OUI（Organizationally Unique Identifier），组织唯一标识符，由 IEEE 分配给厂商
- 后 3 字节：网络接口标识符，由厂商自行分配

示例：`40-55-82-0A-8C-6D`
- 40-55-82：组织唯一标识符
- 0A-8C-6D：网络接口标识符

### 表示格式
| 系统 | 格式 |
|------|------|
| Windows | 40-55-82-0A-8C-6D |
| Linux/Android/Mac/iOS | 40:55:82:0A:8C:6D |
| Packet Tracer | 4055.820A.8C6D |

> 当 48 位全为 1 时，代表广播地址：`FF-FF-FF-FF-FF-FF`

### 查看与修改
- **查看 MAC 地址**：`ipconfig /all`（Windows）、`ifconfig`（Mac/Linux）
- **修改 MAC 地址**：更改适配器选项 → 属性 → 配置 → 高级 → 网络地址
- 有时可以通过修改 MAC 地址蹭网

## ARP 协议

**ARP（Address Resolution Protocol）**：地址解析协议，通过 IP 地址获取 MAC 地址。

### ARP 缓存
- 获取成功后，会缓存 IP 地址与 MAC 地址的映射信息
- 通过 ARP 广播获取的 MAC 地址属于动态缓存，存储时间较短（默认 2 分钟）

### 相关命令
| 命令 | 说明 |
|------|------|
| `arp -a [主机地址]` | 查询 ARP 缓存 |
| `arp -d [主机地址]` | 删除 ARP 缓存 |
| `arp -s 主机地址 MAC地址` | 增加静态缓存 |

### RARP 协议
RARP（Reverse Address Resolution Protocol）：逆地址解析协议，将 MAC 地址转换为 IP 地址。后来被 BOOTP、DHCP 取代。

## ICMP 协议

**ICMP（Internet Control Message Protocol）**：互联网控制消息协议
- IPv4 中称为 ICMPv4，IPv6 中称为 ICMPv6
- 通常用于返回错误信息（如 TTL 值过期、目的不可达）
- ICMP 的错误消息总是包括了源数据并返回给发送者

## IP 地址

### 概述
- IP 地址（Internet Protocol Address）：互联网上的每一个主机都有一个 IP 地址
- **IPv4**：32 bit（4 字节），2019 年 11 月 25 日全球 IP 地址已用完
- **IPv6**：128 bit（16 字节）

示例：`192.168.1.10`

```
1100 0000 . 1010 1000 . 0000 0001 . 0000 1010
  192        168          1           10
```

### IP 地址的组成
IP 地址由 2 部分组成：
1. **网络标识（网络 ID）**
2. **主机标识（主机 ID）**

通过**子网掩码（subnet mask）** 可以得知网络 ID 和主机 ID：
- 主机所在的网段 = 子网掩码 & IP 地址
- 同一网段：不需要路由器转发
- 不同网段：需要路由器转发

### IP 地址分类

| 类别 | 默认子网掩码 | 网络ID范围 | 说明 |
|------|-------------|-----------|------|
| A 类 | 255.0.0.0 | 1~126 | 大型网络 |
| B 类 | 255.255.0.0 | 128~191 | 中型网络 |
| C 类 | 255.255.255.0 | 192~223 | 小型网络 |
| D 类 | - | 224~239 | 多播地址 |
| E 类 | - | 240~255 | 保留使用 |

> 只有 A、B、C 类地址才能分配给主机。主机 ID 全 0 表示网段，全 1 表示广播地址。

### 特殊地址
- `127.0.0.1`：本地环回地址（Loopback），代表本机
- `0.0.0.0`：表示任意地址

## 子网划分

### 为什么要进行子网划分？
避免浪费 IP 地址资源。例如：
- 200 台主机用 C 类网段（254 个可用地址），浪费不大
- 500 台主机用 B 类网段（65534 个可用地址），浪费极大

### 等长子网划分
将一个网段等分成多个子网，每个子网的可用 IP 地址数量相同。

示例：`192.168.0.0/24` 等分成 2 个子网
- A 子网：`192.168.0.1~192.168.0.126`，掩码 `255.255.255.128/25`
- B 子网：`192.168.0.129~192.168.0.254`，掩码 `255.255.255.128/25`

### 变长子网划分
每个子网的可用 IP 地址数量可以不同。

### CIDR 表示法
**CIDR（Classless Inter-Domain Routing）**：无类别域间路由
- `192.168.1.100/24`：子网掩码有 24 个 1，即 `255.255.255.0`
- `123.210.100.200/16`：子网掩码有 16 个 1，即 `255.255.0.0`

### 超网
超网是将多个连续的网段合并成一个更大的网段。与子网划分相反。
- 合并 `192.168.0.0/24` 和 `192.168.1.0/24` → `192.168.0.0/23`

### 判断子网还是超网
- 子网掩码位数比默认多 → **子网**
- 子网掩码位数比默认少 → **超网**
