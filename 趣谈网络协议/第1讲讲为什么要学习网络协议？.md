# 第1讲 为什么要学习网络协议

## 协议三要素

协议是计算机之间通信的约定，具备三要素：

- **语法**：内容的格式和规则。比如 HTTP 响应必须先状态行，再头部，再正文。
- **语义**：内容代表的含义。比如状态码 200 表示成功，404 表示未找到。
- **顺序**：操作的先后次序。先发请求，再收响应。

## 双十一购物：一个网络包的生命周期

以在浏览器输入 `https://www.kaola.com` 购物为例，看看网络包经历了什么：

1. **DNS 解析**：浏览器只知道域名，通过 DNS 或 HTTPDNS 查询得到 IP 地址 `106.114.138.24`
2. **应用层封装**：浏览器打包 HTTP/HTTPS 请求，包含"买什么、买多少"
3. **传输层封装**：TCP 协议封装，填入浏览器端口和服务器端口（443），保证可靠到达
4. **网络层封装**：IP 协议封装，填入源 IP 和目标 IP
5. **路由决策**：操作系统判断目标 IP 不在本地网段，需发往网关。通过 ARP 获取网关 MAC 地址
6. **MAC 层封装**：填入源 MAC 和目标 MAC（网关），网卡发包
7. **网关转发**：路由器根据路由表决定下一跳，最终到达服务器
8. **服务端处理**：层层解封装，通过 RPC 协调后端服务（订单、库存、支付），返回 HTTPS 响应

总结：**网络包是层层封装、层层解封装的过程。**
