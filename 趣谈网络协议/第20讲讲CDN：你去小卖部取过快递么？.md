# 第17讲 CDN

CDN（Content Delivery Network，内容分发网络）将内容缓存到离用户最近的边缘节点。

## 分发系统架构

```
源站 ← 中心节点 ← 区域节点 ← 边缘节点 ← 用户
```

层级缓存，命中边缘节点直接返回；未命中逐级向上，最终回源。

## DNS 调度

```
用户 → 本地DNS → 权威DNS（web.com）
              → CNAME: www.web.cdn.com
              → CDN权威DNS → CNAME → GSLB
              → GSLB根据用户IP/运营商/内容/负载选边缘节点
              → 返回边缘节点IP给用户
```

## 缓存内容

### 静态内容

图片、CSS、JS、静态页面。缓存时间长，用拉取（pull）模式。

### 流媒体

- 支持 RTMP/HLS 协议
- **主动推送**：热点内容预先推送到边缘（避免回源压力）
- **预处理**：转码（超清/标清/流畅）、分片
- **防盗链**：Referer 检查 + 时间戳签名验证

## 动态加速

### 边缘计算模式

将计算逻辑和存储部署到边缘节点，从源站定时同步数据，在边缘直接计算结果返回。

### 路径优化模式

数据仍在源站生成，但通过 CDN 节点间专线优化传输路径：
- 调整 TCP 参数（更激进的发送策略）
- 连接复用（避免临时三次握手）
- 数据压缩
