# 第9讲 网关与路由

## 网关

跨网段通信必须通过网关。网关往往是路由器的某个网口，其 IP 和源主机在同一网段（如 `192.168.1.1` 是 `192.168.1.0/24` 的网关）。

发包到其他网段：判断不在同一网段 → ARP 获取网关 MAC → 目标 MAC 填网关 → 网关按路由表转发。

### 两种模式

| 模式 | IP | MAC | 场景 |
|------|-----|-----|------|
| 转发网关 | 不变 | 每跳变化 | 各网段 IP 不冲突 |
| NAT 网关 | 改变（内/外网转换） | 每跳变化 | 局域网 IP 段冲突 |

NAT 网关：内网访问外网时 SNAT 替换源 IP 为公网 IP；家用路由器就是典型 NAT 网关。关键：MAC 必变，IP 可能变。

## 路由表

```bash
ip route add 10.176.48.0/20 via 10.173.32.1 dev eth0
```

每条路由至少含：目的网络、出口设备、下一跳。

### 策略路由

除目的 IP 外还可按源 IP、入口设备、TOS 等多参数选路：

```bash
ip rule add from 192.168.1.0/24 table 10
ip route add default via 60.190.27.189 dev eth3 table 10
```

## 动态路由

静态路由需手动配置。动态路由协议自动生成路由表。

### 距离矢量（Bellman-Ford）

每路由器维护全局路由表，定期与邻居交换。代表：RIP（<15 跳，小型网络）。缺点：好消息快坏消息慢，每次发全表开销大。

### 链路状态（Dijkstra）

路由器先发现邻居、计算距离，广播链路状态到全网。各节点本地构建拓扑，Dijkstra 算最短路径。**只广播变化部分，收敛快**。

## OSPF（内部网关）

基于链路状态算法，数据中心内部使用。支持多条等价路径负载均衡。

## BGP（外部网关）

自治系统（AS）间路由，重在策略：

| AS 类型 | 特点 |
|---------|------|
| Stub AS | 单一外部连接，不中转 |
| Multihomed AS | 多连接但不中转 |
| Transit AS | 中转流量（骨干网） |

BGP 使用路径矢量路由，在路径中携带 AS 路径信息，避免距离矢量"坏消息传得慢"问题。
