# 第8讲 路由协议

## 路由表

路由器根据路由表转发数据包。每条路由至少包含：
- **目的网络**：目标网段
- **出口设备**：从哪个网口发出
- **下一跳**：下一个路由器的 IP 地址

```bash
ip route add 10.176.48.0/20 via 10.173.32.1 dev eth0
```

### 策略路由

除目的 IP 外，还可按源 IP、入口设备、TOS 等多参数选择路由表，让不同来源的流量走不同路径：

```bash
ip rule add from 192.168.1.0/24 table 10
ip route add default via 60.190.27.189 dev eth3 table 10
```

## 动态路由算法

静态路由需手动配置，网络一变就得改。动态路由协议根据算法自动生成路由表。

### 距离矢量路由（Bellman-Ford）

每个路由器维护全局路由表，定期与邻居交换，根据邻居的距离推算自己的距离。

**代表协议：RIP（适用于小型网络，小于 15 跳）**

缺点：
- 好消息传得快，坏消息传得慢（环路检测需要很长时间）
- 每次发送整个路由表，开销大

### 链路状态路由（Dijkstra）

路由器先发现邻居、计算距离，然后将链路状态广播全网。每个路由器本地构建完整拓扑图，用 Dijkstra 算法算最短路径。

**优点**：只广播变化部分，收敛快；坏消息迅速传播。

## 内部网关协议：OSPF

基于链路状态路由算法，用于数据中心内部。OSPF 能找到多条等价路径进行**负载均衡**，配合 LVS 实现高吞吐接入。

## 外部网关协议：BGP

用于自治系统（AS）之间的路由。不仅是路径远近的问题，还有**策略**——哪些 IP 可以通告、哪些路径可以走。

### AS 类型
- **Stub AS**：单一外部连接，不转发其他 AS 的流量
- **Multihomed AS**：多个外部连接，但不中转
- **Transit AS**：中转流量，如骨干网

BGP 使用**路径矢量路由**（距离矢量的升级版），在路径中包含 AS 路径信息，避免了距离矢量"坏消息传得慢"的问题。
