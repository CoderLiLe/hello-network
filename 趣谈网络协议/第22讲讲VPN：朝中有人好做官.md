# 第19讲 VPN

VPN（虚拟专用网）利用公网建立安全的专用数据传输通道，比公网安全，比专线便宜。

## IPsec VPN

基于 IP 的安全隧道协议，提供三大保障：
- **私密性**：对称加密，密钥通过 IKE（因特网密钥交换）协商
- **完整性**：Hash 摘要，防止篡改
- **真实性**：预共享密钥或数字签名认证

### 建立过程

**阶段一（IKE SA）**：通过 DH（Diffie-Hellman）算法在不传输密钥的情况下协商出对称密钥 K。

DH 算法：双方约定质数 p、q，各生成私钥 a、b，计算出公钥 A、B 交换，各自独立算出相同的对称密钥 K。

**阶段二（IPsec SA）**：用 K 加密传输新的随机对称密钥 M，后续通信使用 M。SA 有过期时间，定期更新。

### 封装模式（ESP）

```
原始IP包 → ESP封装（加密+摘要）→ 新IP头（公网可达）
```

内层 IP 头的协议字段从 TCP 改为 ESP，ESP 尾部标明原始协议。

### 缺点

IP 不面向连接，每个包独立选路，路由查找开销大，速度慢。

## MPLS VPN

### MPLS（多协议标签交换）

在 IP 包外加标签头（20 位标签值 + 3 位实验位 + 1 位栈底标志 + 8 位 TTL）。

标签交换路由器（LSR）维护路由表（FIB）和标签转发表（LFIB）。MPLS 区域内用标签转发（固定路径、快速），边缘节点负责普通路由 ↔ 标签转换。

LDP（标签分发协议）：下游 LSR 向上游分发标签，建立标签交换路径（LSP）。

### MPLS VPN 架构

```
CE → PE → P（MPLS核心，标签转发）→ PE → CE
```

- **PE**：运营商网络边缘设备
- **CE**：客户网络与 PE 连接的设备
- **P**：运营商网络内部路由器

### 解决地址重叠

不同客户可能使用相同私网 IP 段。解决方案：

- **MP-BGP**：在 IPv4 地址前加客户区分符（VPN-IPv4 地址族）
- **VRF**：PE 上每个客户维护独立路由表

### 两层标签转发

- **外层标签**：骨干网 LSP 路径（PE → PE）
- **内层标签**：到达目的 CE 的标识（查 VRF 表）

出口 PE 剥离外层标签后，根据内层标签找到对应的 CE 接口。
