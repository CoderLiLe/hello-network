# 第25讲 容器网络

容器 = 集装箱：**打包** + **标准**。比虚拟机更轻量的隔离。

## namespace（隔离）

Linux namespace 让进程看到独立的网络栈（IP、路由表、端口空间等），由 `ip netns` 命令管理。

创建路由器 namespace 示例：

```bash
ip netns add routerns
ip netns exec routerns sysctl -w net.ipv4.ip_forward=1
# 创建网卡连到 br0
ovs-vsctl --add-port br0 taprouter --set Interface taprouter type=internal
ip link set taprouter netns routerns
ip netns exec routerns ip addr add 192.168.1.1/24 dev taprouter
# 外网网卡连到 br-ex
ip link set taprouterex netns routerns
ip netns exec routerns ip addr add 16.158.1.100/24 dev taprouterex
# NAT 规则
ip netns exec routerns iptables -t nat -A PREROUTING -d 16.158.1.103 -j DNAT --to 192.168.1.3
ip netns exec routerns iptables -t nat -A POSTROUTING -s 192.168.1.3 -j SNAT --to 16.158.1.103
```

## cgroup（资源限制）

cgroup 限制进程使用的 CPU、内存、块设备 IO 等。`net_cls` 子系统用 classid 标记网络包，配合 TC 做流量控制：

```bash
mount -t cgroup -o net_cls net_cls /sys/fs/cgroup/net_cls
mkdir /sys/fs/cgroup/net_cls/a
echo 0x00010010 > /sys/fs/cgroup/net_cls/a/net_cls.classid
# TC 按 cgroup 过滤
tc filter add dev eth0 protocol ip parent 1:0 prio 1 handle 1: cgroup
```

## Docker 网络

### veth pair

容器没有虚拟化软件（qemu-kvm），用 veth pair 代替 TUN/TAP：

```bash
ip link add veth1 type veth peer name veth2
ip link set veth1 master docker0 && ip link set veth1 up
# 获取容器 namespace 并放入网卡
docker inspect '--format={{.State.Pid}}' test  # 得到 pid
ln -s /proc/<pid>/ns/net /var/run/netns/<pid>
ip link set veth2 netns <pid>
ip netns exec <pid> ip addr add 172.17.0.2/24 dev eth0
```

### NAT 出网

容器访问外网通过 SNAT：

```bash
-A POSTROUTING -s 172.17.0.0/16 ! -o docker0 -j MASQUERADE
```

conntrack 记录连接映射，返回包自动 DNAT 回去。

### 端口映射

外部访问容器服务两种方式：

- **docker-proxy**：用户态进程监听宿主机端口转发
- **DNAT**：`-A DOCKER -p tcp --dport 10080 -j DNAT --to 172.17.0.2:80`
