# 第34讲 知识串讲：双十一的全链路

以双十一下单为线索，串起全部网络协议知识。分十个阶段。

## 阶段一：部署电商平台

**云平台架构**：华东主站 + 华北华南，每个 Region 多可用区。可用区内含机柜、接入/汇聚交换机、计算节点（OVS）。

**VPC 规划**：创建 VPC 分配 IP 段，每个可用区一个 Subnet。VPC 间 VXLAN 隔离。

**PaaS 层**：数据库（跨可用区主备 + 分布式实例）、缓存集群。

**应用层**：Controller → 组合服务 → 基础服务，RPC + 注册中心。OVS + VXLAN 隧道跨物理机互通。

**网关**：SLB 负载均衡（公网 IP + NAT 转私网），智能 DNS 就近访问，CDN 分发静态资源。

## 阶段二：BGP 路由广播

边界路由器通过 BGP 将公网 IP 广播到运营商，全世界知道如何到达你的网站。

## 阶段三：DNS 域名解析

手机 → eNodeB → MME 鉴权 → SGW/PGW 隧道 → 手机获取 IP。

DNS 解析流程：本地 DNS → 根 DNS → .com 顶级 DNS → 权威 DNS → GSLB（根据来源运营商和地理，返回最近 Region 的 SLB IP）。

手机 App 可绕过传统 DNS，直接用 HTTPDNS 获取 IP。
