# 第37讲 知识串讲：双十一的全链路

以双十一下单为线索，串起全部网络协议知识，分十个阶段。

## 阶段一：部署电商平台

华东主站 + 华北华南，每 Region 多可用区。VPC 分配 IP 段 + Subnet，VXLAN 隔离租户。数据库（跨可用区主备 + 分布式）、缓存集群。应用层：Controller → 组合服务 → 基础服务（RPC + 注册中心）。OVS + VXLAN 隧道跨物理机互通。SLB 公网 IP + NAT 转私网，智能 DNS，CDN 分发静态资源。

## 阶段二：BGP 路由广播

边界路由器通过 BGP 将公网 IP 广播到运营商，全世界知道如何到达你的网站。

## 阶段三：DNS 解析

手机 → eNodeB → MME 鉴权 → SGW/PGW 隧道 → 手机获 IP。本地 DNS → 根 DNS → .com 顶级 → 权威 DNS → GSLB（按运营商和地理返回最近 SLB IP）。App 可用 HTTPDNS 绕过传统 DNS。

## 阶段四：CDN 加载静态资源

静态资源 CNAME 指向 CDN 权威 DNS → GSLB → 最近边缘节点 IP。缓存未命中则逐级回源拉取。

## 阶段五：建立 TCP + TLS 连接

**三次握手**：SYN → SYN+ACK → ACK，双方进入 ESTABLISHED。

**TLS 握手**：Client Hello → Server Hello → 证书验证 → Client Key Exchange（Pre-master 用公钥加密） → 三个随机数生成对称密钥 → Change Cipher Spec 加密通信。

## 阶段六：封装下单网络包

HTTP POST（JSON body）→ TCP 层（端口+序列号）→ IP 层（源 IP + SLB IP）→ MAC 层（ARP 获取网关 MAC）。跨网段发往默认网关。

## 阶段七：穿行互联网

手机 → GTP 隧道（SGW→PGW）→ NAT 转公网 IP → 运营商 AS 间 BGP 路由 → 逐跳换目标 MAC（IP 不变）→ 云平台边界路由器 → SLB。

TCP 滑动窗口保证可靠传输。TCP 层同连接内不会重复下单，但连接断开后 HTTP 重试需服务端幂等。

## 阶段八：进入数据中心

SLB 公网口 NAT 转私网 IP → VXLAN 隧道（VPC ID）→ OVS 解封装 → HAProxy 虚拟机。

## 阶段九：微服务 RPC 调用链

HAProxy（四层）→ Controller（HTTP 解析）→ Dubbo（Hessian2 + Netty）→ 下单服务 → 库存/优惠券服务（CAS 乐观锁扣库存）→ VXLAN 跨物理机。

## 阶段十：下单入库

库存扣减用 CAS（当前值+预期值+版本号），基于状态非动作，符合 RESTful 幂等设计。写入分布式数据库，下单完成。
