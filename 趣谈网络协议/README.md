# "趣谈网络协议" 专栏笔记

> 讲师：刘超（网易研究院云计算技术部首席架构师）
> 来源：极客时间

## 专栏简介

本专栏由网易研究院首席架构师刘超主讲，用故事化的方式讲解网络协议。与传统的教科书式教学不同，本专栏：

- **用故事讲技术**：从双十一购物、宿舍组网等身边场景出发
- **跨层串讲**：将各层协议的关系串联起来，而非孤立讲解
- **聚焦云原生**：重点讲解云计算、容器、微服务中的网络协议

## 核心观点

1. **分层的本质**：复杂程序都要分层，每层专注本层的事情
2. **完整包原则**：在网络上跑的包都是完整的，可以有下层没上层，不能有上层没下层
3. **IP与MAC**：IP用于跨网络寻址（国家），MAC用于局域网通信（城内）
4. **协议三要素**：语法、语义、顺序
