## 专栏简介

用故事化方式讲解网络协议，从双十一购物、宿舍组网等场景出发，跨层串讲各层协议，重点覆盖云计算、容器、微服务中的网络应用。

## 核心观点

1. **分层的本质**：复杂程序都要分层，每层专注本层职责
2. **完整包原则**：网络上跑的包都是完整的，可有下层无上层，不可有上层无下层
3. **IP与MAC**：IP用于跨网寻址（门牌号），MAC用于局域网通信（身份证）
4. **协议三要素**：语法（格式）、语义（含义）、顺序（时序）
