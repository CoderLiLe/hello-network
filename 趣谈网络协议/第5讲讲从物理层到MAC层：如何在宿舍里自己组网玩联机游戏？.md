# 第5讲 从物理层到VLAN

## 物理层：宿舍组网的起点

两台电脑直连：网线需要交叉线（1-3、2-6 交叉接法），配上同网段 IP 即可互通，形成一个最小局域网（LAN）。

三台以上：用集线器（Hub）。Hub 工作在物理层，**将收到的每个字节复制到所有其他端口**，广播模式。

## 数据链路层（MAC 层）

MAC（Medium Access Control，媒体访问控制）解决三个问题：

### 1. 谁先发？（多路访问控制）

三种方式：
- **信道划分**：每人一个信道
- **轮流协议**：轮流发送
- **随机接入**：先发，冲突就退避重发——**以太网用的就是这种方式**

### 2. 发给谁？（寻址）

以太网帧格式：目标 MAC（6B）+ 源 MAC（6B）+ 类型（2B，如 IP）+ 数据 + CRC（4B，循环冗余校验）

ARP 协议：已知 IP 求 MAC，在局域网内广播"谁是 X.X.X.X 请回答"，目标机器响应自己的 MAC 地址。机器本地缓存 ARP 结果，有过期时间。

### 3. 出错怎么办？（CRC）

通过 XOR 异或算法计算 CRC 校验值，检测包在传输中是否出错。

## 交换机：智能的二层设备

Hub 无脑广播，机器多了冲突严重。交换机记住每个端口对应哪台机器的 MAC 地址（**自学习**），只向目标 MAC 所在的端口转发。

**转发表**有老化时间，因为机器的 IP 和所在端口会变化。

## 环路问题与 STP

两台交换机同时连接两个局域网会形成环路，广播包不断复制增殖，MAC 地址表被反复错误更新，导致网络瘫痪。

### STP（生成树协议）

将"有环图"破环为"无环树"，消除环路。

核心概念：
- **Root Bridge（根交换机）**：优先级最高的交换机
- **BPDU**：STP 控制报文，交换机间交换拓扑信息
- **优先级向量**：[Root Bridge ID, Root Path Cost, Bridge ID, Port ID]，值越小越优先

工作过程：初始所有交换机自认是根桥 → 互发 BPDU 比较优先级 → 低优先级胜出，高优先级归顺 → 最终生成无环生成树。

**STP 缺点**：收敛慢，瓶颈链路阻塞浪费带宽，大规模网络影响面大。

## VLAN：虚拟局域网

广播域太大会导致性能下降和安全问题（数据被窃听）。

### 隔离方式

- **物理隔离**：每个部门独立交换机 + 子网，浪费端口
- **VLAN（虚拟隔离）**：一台交换机支持多个 VLAN，通过 802.1Q 标签（12 位 VLAN ID，支持 4096 个）在二层帧头做标记

交换机之间通过 **Trunk 口** 连接，Trunk 口转发所有 VLAN 的包。交换机只将包转发给同 VLAN 的端口。

**VLAN 局限**：4096 个 ID 在大规模云环境不够用，后续 VXLAN 等方案可解决。
