## 阶段四：CDN 加载静态资源

静态资源的 CNAME 指向 CDN 权威 DNS → GSLB → 返回最近边缘节点 IP → 缓存未命中则回源拉取。

## 阶段五：建立连接（TCP + TLS）

**TCP 三次握手**：CLOSED → SYN-SENT → SYN-RCVD → ESTABLISHED。

**TLS 握手**：Client Hello（TLS 版本 + 加密套件 + 随机数1）→ Server Hello（选定套件 + 随机数2）→ 证书 → Client Key Exchange（Pre-master 用公钥加密）→ 三个随机数生成对称密钥 → Change Cipher Spec 加密通信。

## 阶段六：封装下单网络包

HTTP POST 请求（JSON 正文）→ TCP 层（端口号 + 序列号）→ IP 层（源 IP + 目标 SLB IP）→ MAC 层（ARP 获取网关 MAC）。

不同网段 → 发往默认网关（DHCP 分配）。
