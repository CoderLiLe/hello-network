# 第7讲 网关与NAT

## 网关是什么

跨网段通信必须通过网关。**网关往往是一个路由器的某个网口**，其 IP 地址和源主机在同一网段（如 `192.168.1.1` 是 `192.168.1.0/24` 网段的网关）。

发往其他网段的包流程：
1. 判断目标 IP 不在同一网段
2. 通过 ARP 获取网关的 MAC 地址
3. 目标 MAC 填写网关 MAC（目标 IP 不变）
4. 网关收到后，根据路由表选择出口转发

## 两种网关模式

### 转发网关（"欧洲十国游"）：IP 不变

中间各网段 IP 不冲突，端到端 IP 保持不变。每经过一个局域网，**MAC 地址变化，IP 地址不变**。

### NAT 网关（"玄奘西行"）：IP 改变

局域网间 IP 段可能冲突（如都用 `192.168.1.x`），需要 Network Address Translation。

**SNAT（源地址转换）**：内网访问外网时，将私有源 IP 替换为公网 IP。家用路由器就是典型的 NAT 网关——内网 `192.168.1.x`，出口被 NAT 成运营商分配的公网 IP。

**关键**：
- MAC 地址过网关必变（换了局域网）
- 转发网关：IP 不变
- NAT 网关：IP 改变（内/外网身份转换）
