# 结束语：放弃完美主义，执行力就是限时限量认真完成

## 创作感悟

写这个专栏花费了近半年时间，从计划的36篇写到了45篇。最大的感悟是：**放弃完美主义，限时限量地完成，才能形成执行力。**

技术人都有完美主义倾向，但完美主义往往与拖延症如影随形。做技术的目的是满足需求，在固定时间点内，把控范围、勇于放弃，以最大努力往完美方向靠近。

## 保持饥渴，脱离舒适区

从 Windows 转 Linux、从存储转 OpenStack、从云计算转微服务——每次转型都在被"鄙视"中成长。怕被鄙视，说明还不够饥渴，还没勇气脱离舒适区。

当你看到突破自己的学习机会，别犹豫，搭上这辆车。十年后你会发现，当年的嘲笑轻视都算不了什么，进步本身才是最重要的。
