# 第40讲 搭建网络实验环境

网络是实验性学科，理论 + 动手才能真掌握。

## 环境搭建（TCP/IP 详解拓扑）

### 1. 创建 Ubuntu 虚拟机（VirtualBox）

两个网卡：
- **Host-only**：笔记本 SSH 登录，稳定
- **NAT**：虚拟机访问互联网

### 2. 安装 Docker + Open vSwitch

```bash
apt-get -y install docker-ce openvswitch-common openvswitch-switch bridge-utils arping
```

### 3. 拉取镜像

```bash
docker pull hub.c.163.com/liuchao110119163/ubuntu:tcpip
```

镜像内置：iproute2、tcpdump、curl、telnet、traceroute 等网络工具。

### 4. 一键启动

```bash
git clone https://github.com/popsuper1982/tcpipillustrated.git
./setupenv.sh enp0s3 hub.c.163.com/liuchao110119163/ubuntu:tcpip
```

脚本要点：
- 每个节点一个容器（--privileged, --net none）
- OVS 创建两个网桥
- pipework 连接容器到网桥
- P2P 网络用 veth pair + ip netns
- 配置路由表、ARP proxy
- iptables MASQUERADE 实现容器出外网

## Open vSwitch 实验

推荐实验：
1. 查看 OVS 架构和模块
2. OpenFlow Controller 下发流表
3. Port VLAN 隔离
4. HTB QoS 限流
5. GRE/VXLAN 隧道租户隔离
6. Flow Table 操作

所有配置保存在本地 JSON 库中，包含网桥、流表、端口、VLAN、绑定、隧道等。
