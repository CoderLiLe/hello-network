# 答疑解惑汇总

涵盖第1-36讲课后思考题与留言精选问答。

## 网络基础 (1-3讲)

**Q: 为什么有了下一跳IP还要通过ARP获取MAC？**
网络包中目标IP是最终目的地，不能中途被覆盖。下一跳IP需要通过ARP转为MAC地址填入目标MAC字段。

**Q: MAC地址可以修改吗？**
可以。MAC地址由OUI（前24位）+扩展标识符（后24位）组成，本设计为唯一，但虚拟化设备和工具可修改。至少应保证局域网内唯一。

**Q: TCP重试会不会导致重复下单？**
不会。TCP层会去重，HTTP层只收到一个请求。但当TCP连接断开时，HTTP会重发请求，此时服务端需实现幂等（根据订单号去重）。

**Q: 为什么要分层？**
复杂程序都要分层，将不同职责分离。如UI与业务逻辑分离、数据库被基础服务层屏蔽，网络协议分层也是同样的架构思想。

**Q: 网络号、IP、子网掩码、广播地址的先后关系？**
网络管理员先规划网段，确定网络号；子网掩码由网络号位数决定；广播地址为主机号全1。规划完后，第一个地址通常给网关。

**Q: MTU 1500 的含义？**
MTU是以太网二层的最大传输单元。IP包超过MTU需分片。TCP的MSS = MTU - IP头 - TCP头，即不分片时的最大TCP内容。

## 数据链路层与网络层 (4-8讲)

**Q: DHCP网络中手动配IP会冲突吗？**
会。DHCP服务器可能将同一IP分配给其他机器，导致ARP返回两个应答。客户端可在接受IP前发送ARP检测冲突；服务器可先ping检测。

**Q: DHCP Offer和ACK是单播还是广播？**
取决于客户端协议栈实现。若未配置IP时无法接收单播，则通过广播交互；若协议栈能力足够，可单播。

**Q: ARP广播在多个交换机下有什么问题？**
会形成环路和广播风暴。交换机学习机制会被打乱，同一广播包反复复制增殖，必须用STP协议破环。

**Q: STP有什么缺点？**
拓扑变化收敛慢，全网只有一棵生成树，链路阻塞后不承载流量造成带宽浪费，大规模网络影响面大。

**Q: 交换机如何选举根桥？**
网桥ID = 优先级 + MAC地址，ID最小的成为根桥。默认优先级均为32768，MAC最小的胜出。可手动配置更小优先级。

**Q: Port-based VLAN 和 802.1Q VLAN 的区别？**
Port-based VLAN仅在一台交换机内生效，出端口不带VLAN ID。802.1Q的VLAN标签跨交换机有效。

**Q: NAT是如何知道返回包该还给哪个内网机器的？**
通过conntrack（连接跟踪）机制。内核维护连接跟踪表，记录{源IP,源端口,目标IP,目标端口}的映射关系，NAT时修改源地址并记录，返回时根据映射反向NAT。

**Q: NAT能建立多少连接？**
取决于目标IP和端口的多样性。所有机器访问同一目标IP+端口时，受源端口数限制（65535）；访问不同目标则远超此数。

**Q: 多线BGP机房是怎么回事？**
IDC申请自己的IP段和AS号，通过BGP广播到各运营商网络，各运营商的骨干路由设备判断最佳路由。

## 传输层 (9-11讲)

**Q: TCP如何才算一个连接？**
TCP两端维护连接的数据结构（状态、序列号、窗口等），双方通过三次握手建立共享状态，即为"连接"。

**Q: TIME_WAIT状态太多怎么办？**
原因：大量短连接频繁创建释放。解决：开启tcp_tw_recycle/tcp_tw_reuse；或用SO_LINGER强制RST关闭。

**Q: TCP起始序列号如何计算？**
ISN = M + F(localhost, localport, remotehost, remoteport)。M每4毫秒+1，F是Hash算法（如MD5），防止序列号被猜测攻击。

## 应用层 (12-17讲)

**Q: HTTP keepalive是什么？**
一次TCP连接中持续发送多份数据而不断开，减少TCP连接建立次数和TIME_WAIT状态。需设置合理的keepalive timeout。

**Q: 如何优化HTTPS性能？**
使用QUIC（基于UDP）省略TCP三次握手；使用TLS 1.3通过key_share在一个RTT内完成握手。

## 数据中心与云网络 (18-26讲)

**Q: OpenStack网络模型对应关系？**
早期：Flat、Flat DHCP、VLAN。后来支持VPC，用VXLAN和GRE进行隔离。

**Q: SDN控制器是什么？**
独立的管控面集群，主流开源方案有OpenContrail、OpenDaylight等。流表保存在各宿主机上。

**Q: 容器内部如何访问外部服务？**
通过iptables POSTROUTING的MASQUERADE将容器地址伪装为node IP。也可用Kubernetes的ExternalName Service将外部地址映射为内部域名。

**Q: Calico为什么在公有云上用IPIP模式？**
公有云VPC会检查源IP，非平台分配的IP可能被丢弃。IPIP模式下外层IP仍是云平台分配的地址。

## RPC与微服务 (27-31讲)

**Q: NFS mount后，文件写入如何触发RPC？**
通过VFS（虚拟文件系统）。NFS的inode中file_operations指向nfs_file_read/write等函数，读写文件时自动触发RPC调用。

**Q: Service Mesh中Envoy如何代理所有流量？**
通过iptables规则：PREROUTING将所有入站流量转发到Envoy的15000端口；OUTPUT将所有出站流量也转发到Envoy。Envoy根据服务发现配置完成代理调用。
