# 食用指南

## 学习路径

1. **能力自测**：先做[网络协议能力测试题](https://time.geekbang.org)，找准薄弱点
2. **循序渐进**：按章节顺序学习，每节后完成思考题
3. **答疑参考**：思考后再对照答疑解惑
4. **知识串讲**：学完前36讲后，用"双十一故事"串起全部协议
5. **动手实践**：搭建实验环境，抓包验证

## 关键资源

- 答疑解惑：涵盖第1-36讲思考题详解
- 知识串讲（上中下）：双十一购物完整网络过程
- 知识图谱：全部协议关系图
- 实验环境搭建指南

## 学习建议

- 文字+音频配合使用，音频对图片有补充解释
- 使用划线笔记记录要点，完成后回顾
- 看到有启发的章节，分享给同事一起讨论
