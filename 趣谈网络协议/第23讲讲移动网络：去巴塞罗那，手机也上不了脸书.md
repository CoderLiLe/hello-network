# 第20讲 移动网络

## 演进历程

| 代际 | 特点 | 核心网 |
|------|------|--------|
| 2G | 电话网络 PSTN，模拟信号 | MSC 鉴权 + 计费 |
| 2.5G | 加入分组交换，支持 IP | 增加 SGSN/GGSN |
| 3G | 无线带宽大幅提升（W-CDMA） | Node B + RNC |
| 4G | 控制面/数据面分离，百兆下行 | MME + SGW/PGW |

## 4G 网络架构

```
手机(UE) → eNodeB → MME（控制面）+ SGW → PGW → 互联网
                         ↓
                        HSS（用户签约数据库）
```

- **MME**（控制面核心）：认证鉴权，选择 SGW/PGW
- **SGW**（数据面接待）：本地运营商设备
- **PGW**（出口网关）：归属地运营商设备，分配手机 IP
- **PCRF**：策略和计费控制

## SCTP 协议（控制面传输层）

比 TCP 更适合移动网络：

1. **多宿主**：多个网卡纳入一个联合（association），一条路径失效自动切换
2. **多流**：一个联合中多个独立流，不会相互阻塞
3. **四次握手 + Cookie**：防止 SYN 攻击
4. **消息分帧**：借鉴 UDP，保留消息边界
5. **三次挥手**：不保留半关闭状态

## GTP 协议（数据面隧道）

GTP-C（控制面，基于 UDP）建立两段隧道：
- 隧道一：eNodeB ↔ SGW
- 隧道二：SGW ↔ PGW

GTP-U（数据面）封装手机原始 IP 包，类似 IPsec 的乘客/隧道/承载三层结构。GTP-C 自带序列号和重传机制，不依赖 TCP。

## 上网流程（Attach）

手机 → eNodeB → MME 鉴权 → MME 通知 SGW 创建会话 → SGW 通知 PGW 创建会话 → PGW 分配 IP → 隧道建立完成 → 手机通过 GTP 隧道上网。

## 异地上网

SGW 在本地运营商（如巴塞罗那），PGW 在归属地运营商（如国内）。手机 IP 由归属地 PGW 分配，流量经国内运营商出口。上网策略由国内 PCRF 控制（所以到了巴塞罗那也上不了脸书）。
