# 第3讲 ifconfig：IP地址与网卡

## ip addr 命令

```bash
$ ip addr
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536 ...
    inet 127.0.0.1/8 scope host lo
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 ...
    link/ether fa:16:3e:c7:79:75 brd ff:ff:ff:ff:ff:ff
    inet 10.100.122.2/24 brd 10.100.122.255 scope global eth0
```

## IP 地址

IP 地址是网卡在网络世界的通讯地址，32 位，分四段，每段 8 bit。32 位不够用，于是有了 128 位的 IPv6。

### CIDR（无类型域间选路）

打破 A/B/C 类的划分方式，用 `IP/前缀位数` 表示，如 `10.100.122.2/24`：前 24 位是网络号，后 8 位是主机号。

- **广播地址**：主机号全 1，如 `10.100.122.255`
- **子网掩码**：网络号位全 1，如 `255.255.255.0`
- **网络号**：IP & 子网掩码

### 公有与私有 IP

私有 IP 段（可在组织内部重复使用）：
| 类别 | 私有IP范围 |
|------|-----------|
| A | 10.0.0.0 ~ 10.255.255.255 |
| B | 172.16.0.0 ~ 172.31.255.255 |
| C | 192.168.0.0 ~ 192.168.255.255 |

最常见的家庭网段：`192.168.0.x/24`，`192.168.0.1` 通常是路由器地址，`192.168.0.255` 是广播地址。

### scope 含义

- `global`：网卡可对外通信
- `host`：仅本机通信（如 lo 回环接口 `127.0.0.1`）

## MAC 地址

`link/ether fa:16:3e:c7:79:75`，6 字节，十六进制表示，号称全球唯一。

**IP vs MAC**：IP 有远程定位功能（门牌号），MAC 是唯一标识（身份证）。MAC 通信范围局限于一个子网内，跨子网必须用 IP。

## 网络设备状态

`<BROADCAST,MULTICAST,UP,LOWER_UP>`

- UP：网卡已启动
- BROADCAST：支持广播
- MULTICAST：支持多播
- LOWER_UP：物理链路正常（网线插着）

### MTU

最大传输单元 1500 字节，是以太网二层的限制。MAC 头 + 正文（含 IP、TCP、HTTP 头）不超过 1500 字节，超过需分片。

### qdisc（排队规则）

`pfifo_fast` 包含三个优先级的 band（0 > 1 > 2），数据包按 TOS（IP 头中的服务类型）分配到不同 band。高优先级 band 有数据时，不处理低优先级 band。
