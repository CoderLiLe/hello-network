## 阶段七：穿行互联网

手机 → GTP 隧道（SGW→PGW）→ NAT（私网 IP 转公网 IP）→ 运营商 AS 网络 → BGP 路由 → 逐跳换目标 MAC 到达云平台边界路由器 → SLB。

每跳只换 MAC，目标 IP 不变。各 AS 间 eBGP 广播路由，内部 iBGP。

TCP 滑动窗口：已 ACK / 已 ACK 未交应用 / 未 ACK / 空闲缓存。超时未 ACK 则重传。TCP 层不会导致重复下单（同连接内只保存一份），但连接断开后 HTTP 层重试需要幂等。

## 阶段八：进入数据中心

SLB 公网口 → NAT 转私网 IP → 虚拟路由 → VXLAN 隧道（VPC 的 VXLAN ID）→ OVS 解封装 → HAProxy 虚拟机。

## 阶段九：微服务调用链

HAProxy（四层）→ Controller（HTTP 解析）→ Dubbo RPC（Hessian2 + Netty）→ 下单服务 → 调用库存/优惠券服务 → VXLAN 跨物理机。

## 阶段十：下单入库

库存扣减用 CAS 乐观锁（当前值 + 预期值 + 版本号），基于状态而非动作，符合 RESTful 幂等设计。最终写入分布式数据库。
