# 第23讲 云中网络安全与QoS

## 安全组与 iptables

公有云上的虚拟机建议只开放必要端口，其他全关。通过安全组实现 ACL 控制。

### Netfilter 五节点

```
PREROUTING → 路由判断 → FORWARD → POSTROUTING
                ↓
              INPUT → 本机 → OUTPUT
```

iptables 在五个节点插入 hook 函数处理包。

### iptables 四表

| 表 | 功能 | 主要链 |
|----|------|--------|
| raw | 跳过连接跟踪 | PREROUTING, OUTPUT |
| mangle | 修改包头 | 全部五个链 |
| nat | 地址转换 | PREROUTING, OUTPUT, POSTROUTING |
| filter | 包过滤 | INPUT, FORWARD, OUTPUT |

优先级：raw → mangle → nat → filter

### 典型规则

```bash
# 默认拒绝所有
iptables -t filter -A INPUT -s 0.0.0.0/0 -d X.X.X.X -j DROP
# 开放 SSH
iptables -I INPUT -s 0.0.0.0/0 -d X.X.X.X -p tcp --dport 22 -j ACCEPT
# 开放 Web
iptables -A INPUT -s 0.0.0.0/0 -d X.X.X.X -p tcp --dport 80 -j ACCEPT
```

### 云平台安全组

创建安全组 A（Web 层，开放 8080 + 管理员 SSH）、安全组 B（数据库层，仅允许 A 组访问 3306）、规则通过 Agent 自动下发到网桥上的 iptables。

### NAT 与连接跟踪

虚拟机出公网：MASQUERADE（地址伪装），所有虚拟机共享一个公网 IP。conntrack 记录 {源IP,源端口,目标IP,目标端口} 映射，确保返回包正确 NAT 回去。

虚拟机做服务端：需显式配置 DNAT（公网 → 私网）+ SNAT（私网 → 固定公网）。

## 网络 QoS（TC）

只能控制出方向（Shaping），入方向只能丢包（Policy）。

### 无类别队列

- **pfifo_fast**：三个优先级 band，按 TOS 分配
- **SFQ（随机公平队列）**：按 TCP Session hash 分配队列，轮询发送
- **TBF（令牌桶）**：需令牌才能发送，控制发送速率

### 分层令牌桶（HTB）

树形结构，子类可相互借流量：
- **rate**：保证速度
- **ceil**：最大速度（借流量时可突发）

```bash
tc qdisc add dev eth0 root handle 1: htb default 12
tc class add dev eth0 parent 1: classid 1:1 htb rate 100kbps ceil 100kbps
tc class add dev eth0 parent 1:1 classid 1:10 htb rate 30kbps ceil 100kbps
```

### OVS QoS

- 入方向：`ingress_policing_rate`
- 出方向：HTB Queue + 流表 enqueue 动作
